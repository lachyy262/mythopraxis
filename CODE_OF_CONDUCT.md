# Code of Conduct

Mythopraxis is a place for rigorous, imaginative, and culturally responsible collaboration.

## Expected conduct

- Treat contributors, traditions, and affected communities with respect.
- Critique claims and artifacts rather than speculating about people.
- State uncertainty and correct errors openly.
- Welcome negative results and good-faith disagreement.
- Obtain context before adapting culturally specific material.
- Protect private information and report security issues responsibly.

## Unacceptable conduct

Harassment, threats, discriminatory language, sexualized attention, doxxing, plagiarism, deliberate cultural misrepresentation, research fabrication, and retaliation are not permitted in project spaces.

## Enforcement

Use GitHub's reporting tools for conduct concerns. Security-sensitive or privately identifying reports should follow `SECURITY.md`. Maintainers may edit or remove contributions, comments, or participation that violate this code. Decisions should be documented, proportionate, and open to review where privacy permits.

This code applies to repository discussions, issues, pull requests, community spaces, and public representation of the project.
